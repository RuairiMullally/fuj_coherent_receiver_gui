Figure X — Software Layer Architecture

Presentation
Dash GUI
  • Renders controls, telemetry graph, log panel
  • Polls API for status updates (500 ms interval)
  • No hardware access — presentation only
HTTP  (localhost:8000, persistent httpx session)
API Gateway
FastAPI
  • Routes HTTP requests to service methods
  • Pydantic input validation (rejects out-of-range values)
  • Rate limiting per IP (SlowAPI)
  • Exception → HTTP status mapping
  • No business logic — thin routing layer
Python method calls  (via FastAPI thread pool)
Service Layer
FIM24725Service
  • State machine — enforces valid transitions (OFF→STARTING→READY→SHUTTING_DOWN)
  • Power sequencing — VPD before VCC on startup, VCC before VPD on shutdown
  • Bounds enforcement — clamps voltages to safe operating ranges
  • Write-then-verify — reads back every setpoint from hardware
  • Thread safety — RLock serialises all concurrent access
  • Fault handling — emergency shutdown on any failure
SAFETY BOUNDARY
Python method calls  (composition, not inheritance)
Hardware Abstraction
PSU HAL + MCU
  • Translates method calls to protocol-specific commands
  • PSU: UDP socket, SCPI-like command strings
  • MCU: serial UART, ASCII set-confirm protocol
  • Policy-free — no bounds checking, sequencing, or safety logic
UDP (10.10.10.x / 10.10.20.x)  •  UART Serial (115200 baud)
Hardware
Control & Power
  • 2× MP710508 PSUs — OVP/OCP hardware protections (last line of defence)
  • Arduino Uno R3 — SD shutdown pin, AGC/MGC mode pin, ADC telemetry
Electrical  (power rails, control voltages, analog signals)
Optical Module
FIM24725
  • Passive recipient of power and control signals — no programmable interface
  • Receives: VPD, VCC, VOA, OA, GA voltages; SD and MODE digital signals
  • Outputs: peak indicator voltages (PI) and monitor photodiode current (MPD)
Each layer depends only on the layer below it. The service layer (red border) is the single authoritative safety boundary — it enforces state, sequencing, bounds, and verification. Layers above cannot bypass it; layers below are policy-free. The FIM24725 has no programmable interface — it responds only to the electrical signals provided by the hardware layer above.
